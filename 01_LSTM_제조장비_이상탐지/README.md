# 01. LSTM 제조장비 이상탐지

> 불량 라벨이 거의 없는 제조 현장을 가정하고, **정상 데이터만으로 학습하는 LSTM Autoencoder** 이상탐지 파이프라인을 3일 동안 혼자 설계·구현한 프로젝트입니다.

| 항목 | 내용 |
|---|---|
| 기간 · 형태 | SKALA AI 과정 · 3일 솔로 프로젝트 |
| 데이터 | 설비 진동을 가정한 자체 생성 더미 시계열 (sin 기반 정상 패턴 + 노이즈 + 이상 구간) |
| 기술 | Python, PyTorch, LSTM Autoencoder, MSE Reconstruction Error |

---

## 🧩 문제 정의

- 현장에서는 **불량 라벨이 거의 없다** → 지도학습은 현실적으로 어렵습니다.
- 설비 진동은 단일 값보다 **시간에 따른 패턴**이 중요합니다.
- 따라서 "정상 패턴을 학습하고, 그 패턴에서 벗어나는 시점을 찾는다"로 문제를 정의했습니다.

## 🏗️ 파이프라인

```
더미 시계열 생성 → 슬라이딩 윈도우 → 정규화
   → LSTM Encoder → 잠재 벡터 → LSTM Decoder → 복원
   → Reconstruction Error(MSE) → 정상 분포의 99th percentile = Threshold
   → 연속 N 스텝 초과 시 알람
```
