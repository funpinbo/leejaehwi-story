# 정상 데이터만으로 이상탐지 — 라벨이 없을 때의 문제 정의

> **한 줄 요약**: 불량 라벨이 없는 현장 조건에 맞춰 "정상 패턴을 복원하지 못하는 순간 = 이상"으로 문제를 바꾸고, LSTM Autoencoder와 분포 기반 Threshold로 구현했습니다.

---

## 1. 상황

- 제조 설비 이상탐지를 3일 안에 혼자 구현해야 했습니다.
- 에이티아이 현장에서 본 것처럼 **불량은 드물고, 불량 라벨은 거의 존재하지 않습니다.**

## 2. 문제

| 제약 | 의미 |
|---|---|
| 이상 라벨 없음 | 분류 모델(지도학습) 불가 |
| 시계열 데이터 | 한 시점 값이 아니라 **시간 패턴**을 봐야 함 |
| 현장 알람 | False Positive가 많으면 알람 피로로 진짜 이상도 무시됨 |

## 3. 설계 판단

| 선택 | 이유 |
|---|---|
| **Autoencoder** | 정상 데이터만으로 학습 가능. 정상 패턴은 잘 복원하고, 처음 보는 패턴은 복원 오차가 커짐 |
| **LSTM** | 시간 의존성 학습. Cell State의 덧셈 업데이트(`C_t = f_t ⊙ C_{t-1} + i_t ⊙ g_t`)로 기울기 소실 완화 |
| Transformer 대신 LSTM | 3일 · 현장 적용 가능성 검증이 목적. 시퀀스 길이 n에 대해 Attention O(n²) vs LSTM O(n) |
| **MSE** Loss | 큰 오차에 제곱 페널티 → 이상 구간이 정상보다 더 두드러짐 |
| Threshold = **정상 Error 99th percentile** | Error 분포가 정규분포가 아니어서 μ+3σ보다 분포 가정 없는 퍼센타일이 안정적 |
| **연속 N 스텝 초과** 시 알람 | 순간 노이즈로 인한 False Positive 억제 |

## 4. 해결

1. sin 기반 정상 패턴 + Gaussian 노이즈로 더미 데이터 생성, 일부 구간에 이상(진폭·주파수 변화) 삽입
2. 슬라이딩 윈도우로 시퀀스화, **정상 구간만으로 학습**
3. 학습 데이터의 Reconstruction Error 분포에서 99th percentile을 Threshold로 설정
4. 연속 초과 조건으로 알람 생성

## 5. 결과

- 라벨 없이 이상 구간을 찾는 **엔드투엔드 파이프라인** 완성
- 한계도 함께 명시: 더미 데이터는 실제 설비의 복잡한 노이즈를 반영하지 못함 → 실측 데이터 재학습 필수

## 6. 배운 점

- **모델 선택보다 문제 정의가 먼저.** "이상을 분류한다"가 아니라 "정상을 복원한다"로 바꾸는 순간 라벨 문제가 사라졌습니다.
- **Threshold는 통계 + 현장 비용의 문제.** 수치상 최적보다 알람 피로를 줄이는 운영 조건(연속 초과)이 실제로는 더 중요합니다.
- **한계를 숨기지 않는다.** 더미 데이터로 만든 결과는 "구조 검증"이라고 정확히 말하는 것이 신뢰를 줍니다.

---

## 🧪 예제 코드 — `lstm_autoencoder.py`

더미 진동 데이터 생성 → 정상 구간 학습 → 99th percentile Threshold → 연속 초과 알람까지 한 파일로 재현합니다. (CPU에서 수십 초)

```bash
pip install torch numpy
python lstm_autoencoder.py
```

실행 결과 (CPU, seed 고정):

```
Threshold (정상 99th pct): 0.3978
단순 초과 윈도우 수: 319 / 연속 3회 초과 알람 수: 276
알람 중 실제 이상 윈도우 비율(Precision): 93.84%
정상 구간 오탐 알람 수: 17  (단순 초과 기준이었다면 56)
이상 구간 t=2300~2400: 탐지 (첫 알람 t=2307)
이상 구간 t=2600~2700: 탐지 (첫 알람 t=2611)
```

→ 두 이상 구간을 모두 잡으면서, **연속 초과 조건만으로 오탐이 56건 → 17건**으로 줄어드는 것을 확인할 수 있습니다.
Threshold는 학습에 쓰지 않은 정상 구간으로 정했습니다. 학습 데이터로 정하면 복원 오차가 과소평가되어 오탐이 늘어납니다.
