# 02. ACGAN 웨이퍼맵 결함 이미지 생성

> 희귀한 웨이퍼 결함 클래스를 보강하기 위해 GAN으로 결함 이미지를 생성하려다 **Mode Collapse**에 막혔고, 수십 번의 하이퍼파라미터 실험 끝에 **문제를 구조 수준에서 다시 정의**해 ACGAN으로 해결한 독학 프로젝트입니다.

| 항목 | 내용 |
|---|---|
| 형태 | 독학 · 솔로 프로젝트 |
| 데이터 | WM-811K 웨이퍼맵 데이터셋 (정상 약 78%, 결함 유형 간 심한 불균형) |
| 탐색 경로 | 기본 GAN → StyleGAN / CGAN / Stable Diffusion 탐색 → **ACGAN** |
| 평가 | FID + 결함 유형별 형태학적 타당성 육안 검증(에이티아이 도메인 지식) |

## 💡 이 프로젝트에서 가져간 것

- **같은 방법을 다른 설정으로 반복하고 있다면 멈추고 원인을 다시 정의한다.** 이 원칙은 이후 퀀트 트레이딩의 LoRA → RAG 전환, 문서 AGENT의 재생성 → 템플릿 전환에서도 똑같이 적용됐습니다.
- **합성 데이터는 Train에만.** Test Set은 반드시 실제 이미지로만 구성해 Data Leakage를 막았습니다.
- **FID가 낮아도 물리적으로 불가능한 이미지일 수 있다.** Edge-Ring이 중앙에 생기는 식의 오류는 도메인 지식으로만 걸러집니다.
