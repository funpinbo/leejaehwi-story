# 10. MSDF — 데이터 중심 서비스 연결 프레임워크

> 챗봇에 검색 · 크롤링 · 임베딩 · 요약 같은 기능이 붙을 때마다 **챗봇이 "무엇을 어떤 순서로 부르고, 결과를 어디에 두고, 실패하면 어떻게 할지"까지 떠안는** 문제가 있었습니다.
> 이 지휘 역할을 기능 밖으로 꺼내, **서비스는 결과물 이름만 요청하고 연결은 DAG가 정하는** 오픈소스 파이썬 프레임워크로 만들었습니다.

| 항목 | 내용 |
|---|---|
| 기간 | 2026.11 ~ 진행 중 (0.1.0 → 0.2.0 공개) |
| 형태 | 개인 오픈소스 · 1인 개발 (AI 코딩 에이전트 협업) |
| 저장소 | [funpinbo/MSDF](https://github.com/funpinbo/MSDF) · MIT |
| 주요 기술 | Python 3.11+, FastAPI, SQLite(WAL), Pydantic v2, ast 정적 분석, Vue 3 + Vue Flow, SSE |
