# 커리큘럼 설계

## 1. 커리큘럼

| Part | 주제 | 핵심 |
|---|---|---|
| 1 | AI 기본 개념 | ML → DL → LSTM → Attention → LLM, Token / Embedding. Hallucination을 **"LLM은 지식을 DB처럼 꺼내는 게 아니라 다음 토큰을 확률적으로 예측한다"** 는 관점에서 "지식"과 "생각" 두 축으로 설명 |
| 2 | LLM 사용법 | Persona + **Chain-of-Thought**를 PAD 검토 절차로 직접 시연 |
| 3 | MCP / Tool / Skill | PAD 업무용 **Skill 3종**(ECSS 규격 확인 · 규격 버전 확인 · 문서 양식 확정)을 직접 설계해 제시, ReAct 논문과 연결 |
| 4 | Token / Context Window | 토큰을 쓰는 요소(질문 · System Prompt · Chat History · RAG 결과 · Tool 결과)와 절감 전략 |
| 5 | LLM 활용 프로그래밍 | 비개발자도 "코드를 짜려면 이렇게 접근하면 된다" 수준의 방향 제시 |
