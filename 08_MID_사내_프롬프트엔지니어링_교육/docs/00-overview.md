# 프로젝트 개요 — MID · 사내 프롬프트 엔지니어링 교육 (세미나)

> 사내 직원 대부분이 LLM을 단순 질의응답으로만 쓰고 있어, **개발자와 비개발자가 섞인 전 직원**을 대상으로 AI 활용 세미나를 기획부터 대본까지 혼자 설계하고 진행했습니다.

| 항목 | 내용 |
|---|---|
| 형태 | 단독 기획 · 발표 |
| 청중 | 전 직원 (비개발자 비중 큼) |
| 관통 예제 | **우주 부품 PAD 작성** — 처음부터 끝까지 하나의 업무 예제로 설명 |
| 다룬 도구 · 개념 | Claude Code, Codex, Notion, MCP, Skill / Artifact, CoT, ReAct, Toolformer, FlashAttention 등 논문 인용 |

## 1. 성과

- 전 직원 대상 세미나 커리큘럼 · 발표 자료 · 구어체 대본을 **단독으로 설계 · 제작해 실제 진행**
- AI 역사, 프롬프트 엔지니어링, LLM을 활용한 간단한 코드 작성을 직접 시연
- 참석자 대부분이 이런 방식의 LLM 활용을 처음 경험했고, **"이제 제대로 활용할 수 있을 것 같다"** 는 반응

## 2. 회고

- **같은 내용을 청중에 맞게 번역하는 능력**이 팀 전체의 생산성을 높입니다. SKALA 팀 프로젝트에서 비전공 팀원용 가이드를 만들던 경험이 그대로 쓰였습니다.
- 기법을 맹신하지 않고, **최신 자료 기준으로 여전히 유효한지 재검증**하는 습관이 생겼습니다.
