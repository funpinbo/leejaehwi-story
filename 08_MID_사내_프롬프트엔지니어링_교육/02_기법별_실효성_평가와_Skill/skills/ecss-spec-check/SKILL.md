# ECSS 규격 확인 Skill

## 입력
- 부품 번호, 부품 종류(예: 세라믹 커패시터), 프로젝트 Class

## 절차
1. 부품 종류를 ESCC 부품군 분류(Capacitor, Resistor, …)로 매핑한다.
2. 사내 규격 목록(메타데이터 DB)에서 해당 부품군에 `APPLIES_TO` 관계가 있는 규격을 조회한다.
3. Generic → Detail 순서로 정리하고, 각 규격이 참조하는 하위 규격(`REFERENCES`)을 함께 나열한다.
4. 각 규격마다 **근거 조항**(문서 번호 + 조항 번호 + 원문 인용)을 붙인다.

## 규칙
- 사내 규격 목록에 없는 규격은 기억으로 만들어내지 말고 "목록에 없음 — 확인 필요"로 표시한다.
- Revision은 이 Skill에서 확정하지 않는다 → `spec-revision-check`로 넘긴다.

## 출력
| 규격 | 종류 | 근거 조항 | 참조 하위 규격 |
|---|---|---|---|
