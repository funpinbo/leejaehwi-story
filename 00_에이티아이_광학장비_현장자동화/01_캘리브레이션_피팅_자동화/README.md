# 캘리브레이션 피팅 자동화 — 감으로 하던 반복 작업을 관계식으로

> **한 줄 요약**: 조명 설정값과 카메라 GrayValue 사이의 단조 증가 관계를 수식으로 정의해, 목표값만 넣으면 설정값이 계산되는 도구를 만들었고 캘리브레이션 시간을 약 44% 줄였습니다.

---

## 1. 상황

- 웨이퍼 검사 장비를 현장에 셋업할 때마다 **조명 캘리브레이션**이 필요했습니다.
- 엔지니어가 조명 설정값을 조금씩 바꾸고 → 카메라 이미지의 GrayValue를 눈으로 확인하고 → 다시 바꾸는 작업을 반복했습니다.
- 장비 1대당 **약 3시간**, 60여 대 셋업 일정에서 가장 큰 병목이었습니다.

## 2. 문제

- 작업 자체는 "목표 GrayValue에 맞는 조명값 찾기"라는 단순한 문제인데, **매번 탐색을 처음부터** 하고 있었습니다.
- 조건: 현장 PC 대부분에 Python이 없고 설치 권한도 없음 → **누구나 바로 열 수 있는 도구**여야 했습니다.

## 3. 시도와 판단

| 고민 | 판단 |
|---|---|
| 측정값을 쌓아보니 조명값이 커질수록 GrayValue가 **단조 증가** | 몇 개 점만 측정하면 관계식으로 나머지를 예측할 수 있다 |
| Python으로 만들면 더 정교하게 할 수 있음 | 현장에서 못 쓰면 의미가 없다 → **Excel** 선택 |
| 수식이 셀에 보이는 Excel의 특성 | 투명성 확보, 내가 없어도 다른 엔지니어가 수정 가능 |

## 4. 해결

1. 조명값을 몇 단계로 바꿔가며 GrayValue를 측정 (샘플 몇 점)
2. Excel `LINEST`로 관계식(다항 피팅)의 계수를 계산
3. **역함수 방향으로 계산**: 목표 GrayValue를 입력하면 필요한 조명값이 바로 나오도록 구성
4. 조건부 서식으로 허용 범위 밖 값은 색으로 표시
5. 3~4대에서 직접 검증한 결과를 보여주고 현장에 배포

## 5. 결과

- 캘리브레이션 시간 **3시간 → 1시간 40분 (약 44% 단축)**
- 다른 엔지니어도 별도 교육 없이 바로 사용

## 6. 배운 점

- **반복 작업 = 아직 정의되지 않은 함수.** 사람이 감으로 반복하는 작업 안에는 대부분 관계식이 숨어 있습니다. 이 깨달음이 AI 개발로 넘어오게 된 출발점입니다.
- **도입 장벽이 기술 선택을 결정한다.** 같은 문제를 지금 푼다면 FastAPI + 브라우저 UI로 설치 없이 쓰게 하고, 중앙에서 관계식을 업데이트하게 만들 것입니다.
- **신뢰는 검증 결과로 얻는다.** "이 값이 맞냐"는 반응은 설명이 아니라 실제 장비에서의 재현으로만 해소되었습니다. 지금도 AI 결과물을 설계할 때 **근거를 보여줄 수 있는 구조**를 먼저 생각합니다.

## 🧪 예제 코드 — `calibration_fit.py`

당시 Excel로 했던 작업을 Python으로 재현했습니다. 측정값 몇 점으로 다항 피팅을 하고, 목표 GrayValue에 맞는 조명값을 역으로 찾습니다.
(수치는 실제 장비 값이 아닌 예시입니다.)

```bash
python calibration_fit.py
```

```

목표 GrayValue  60 → 조명 설정값 약 21.9
목표 GrayValue 120 → 조명 설정값 약 40.9
목표 GrayValue 180 → 조명 설정값 약 62.2
```
