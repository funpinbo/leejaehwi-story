# 이미지 패턴으로 공정 이상 특정 — "어디서만 다른가"로 원인 좁히기

> **한 줄 요약**: 검사 이미지에서 반복되는 이상 패턴이 **모든 LOT이 아니라 특정 LOT에서만** 나타난다는 점에 주목해, 광학계가 아닌 공정 장비 문제임을 가설로 세우고 비교 테스트로 확인했습니다.

---

## 1. 상황

- 특정 시기부터 검사 이미지에 **주기적인 패턴 이상**이 반복적으로 나타났습니다.
- 광학 엔지니어 입장에서 가장 먼저 의심되는 것은 당연히 광학계(조명·렌즈·카메라)였습니다.

## 2. 문제

- 원인이 광학계인지, 웨이퍼 자체(공정)인지 구분하지 못하면 엉뚱한 곳을 계속 조정하게 됩니다.

## 3. 판단 과정

| 관찰 | 추론 |
|---|---|
| 광학계 문제라면 **모든 LOT**에서 동일하게 나타나야 함 | 그런데 **특정 LOT에서만** 반복됨 |
| 이미지 패턴을 물리 구조 관점에서 보니 **기판 표면의 주기 패턴**이 다름 | 광학이 아니라 **공정 쪽**일 가능성이 높음 |
| 확신이 없는 상태에서 결론을 내리면 위험 | **검증 가능한 테스트를 제안**하는 형태로 접근 |

## 4. 해결

1. "이런 패턴이 특정 LOT에서만 보이는데, 다른 공정 LOT과 비교 테스트를 해볼 수 있을까요?"라는 **가설 형태**로 요청
2. 타 공정 LOT과 비교 → 공정 장비 이상 확인
3. 만약 가설이 틀렸다면 다시 광학계를 분석할 계획이었음

## 5. 결과

- 광학계를 불필요하게 재조정하지 않고, **공정 장비 이상을 특정**
- 현장 동료에게 "광학 엔지니어가 공정 문제를 찾았다"는 신뢰를 얻는 계기

## 6. 배운 점

- **비교 기준을 잡으면 원인의 위치가 보인다.** "이상하다"가 아니라 "A에서는 정상, B에서만 이상"으로 말할 수 있어야 합니다.
- **결론이 아니라 가설을 제안한다.** 내 판단이 틀릴 수 있다는 전제에서 검증 가능한 실험을 제안하는 것이 협업에서도 더 잘 받아들여졌습니다.
- 이후 LSTM 이상탐지 프로젝트에서 Threshold만 정하는 것이 아니라 **"이상이 감지됐을 때 원인 분석을 위해 무엇을 함께 기록해야 하는가"** 를 설계 단계에서 고민한 이유가 이 경험입니다.

---

## 🧪 예제 코드 — `lot_pattern_compare.py`

LOT별 이미지의 행 방향 밝기 프로파일에 FFT를 적용해 **주기 성분**을 비교하는 예제입니다.
정상 LOT의 주기 성분 분포를 기준으로, 기준에서 크게 벗어나는 LOT을 찾아냅니다. (합성 이미지 사용)

```bash
python lot_pattern_compare.py
```
