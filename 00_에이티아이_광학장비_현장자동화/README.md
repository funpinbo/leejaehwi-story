# 00. 에이티아이 · 광학 장비 현장 자동화

> 반도체 웨이퍼 검사 장비의 광학계를 설계·셋업하면서, **반복 업무를 데이터로 정의하면 자동화할 수 있다**는 것을 처음 체감한 경험입니다.
> AI 엔지니어로 전환하게 된 출발점입니다.

| 항목 | 내용 |
|---|---|
| 기간 | 2024.02 ~ 2025.03 |
| 소속 | 에이티아이(주) 광학개발팀 · 광학설계 엔지니어 |
| 업무 | 웨이퍼 검사 장비 광학계 설계·셋업, 현장 셋업 60여 대(청주·천안·화성) |
| 도구 | Excel(LINEST, 조건부 서식), 이미지 분석, 다중파장 조명 실험 |

---

## 🎯 주요 성과

- 캘리브레이션 시간 **3시간 → 1시간 40분 (약 44% 단축)**
- 검사 이미지 패턴 분석으로 **특정 LOT의 공정 장비 이상을 특정**
- 다중파장(IR 1100~1300nm · RGBW) 조명 비교 실험으로 결함 검출 최적 조건 도출
- 현장 셋업 표준 매뉴얼 제작

---

## 📚 경험 정리

| # | 경험 | 한 줄 요약 | 예제 코드 |
|---|---|---|---|
| 01 | [캘리브레이션 피팅 자동화](./01_캘리브레이션_피팅_자동화) | 수동 반복 조정을 `조명값 ↔ GrayValue` 관계식으로 바꿔 44% 단축 | `calibration_fit.py` |
| 02 | [이미지 패턴으로 공정 이상 특정](./02_이미지패턴으로_공정이상_특정) | "모든 LOT이 아니라 특정 LOT에서만" 반복되는 패턴으로 원인 위치를 좁힘 | `lot_pattern_compare.py` |

---

## 💡 이 프로젝트에서 가져간 것

1. **기술적 최선보다 실제로 쓰이는 도구가 먼저다.** Python 설치 권한도 없는 현장이라 Excel로 만들었고, 그래서 바로 쓰였습니다.
2. **도입의 핵심은 신뢰다.** 수식 결과를 믿지 못하던 동료들에게 3~4대에서 직접 검증 결과를 보여준 뒤에야 쓰이기 시작했습니다.
3. **이상은 숫자가 아니라 맥락으로 본다.** "어디서, 언제부터, 무엇과 비교해서" 다른지를 보면 원인의 위치가 좁혀집니다.
