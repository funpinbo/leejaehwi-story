# Event Study — 뉴스를 "유가에 대한 영향"이라는 숫자로 바꾸기

> **한 줄 요약**: 뉴스 원문을 그대로 모델에 넣는 대신, 임베딩 → 클러스터링으로 "어떤 종류의 사건인지"를 묶고, 클러스터별로 사건 전후 유가가 평소 대비 얼마나 움직였는지(비정상 수익률)를 계산해 예측 모델의 피처로 만들었습니다.

---

## 1. 상황

- 유가 예측 모델은 가격·재고·환율 같은 정형 시계열만 쓰고 있었습니다.
- 그런데 실제로 유가를 크게 움직이는 것은 **지정학 이벤트, OPEC 발표 같은 비정형 사건**이었습니다.

## 2. 문제

| 문제 | 설명 |
|---|---|
| 텍스트는 모델에 바로 못 넣음 | 뉴스 한 건 한 건은 노이즈가 크고 양이 많음 |
| "어떤 뉴스가 중요한가"의 기준이 없음 | 중요도를 사람이 라벨링할 수 없음 |
| 정형 데이터와 시점 맞추기 | 사건과 가격 변화를 같은 시간축에서 봐야 함 |

## 3. 접근 — Event Study

금융에서 쓰는 Event Study 방법을 비정형 데이터에 적용했습니다.

```
① 뉴스 임베딩 → 클러스터링      : "공급 차질", "수요 둔화", "OPEC 감산" 같은 사건 유형으로 묶기
② 클러스터별 사건일 추출        : 같은 유형의 사건이 발생한 날짜들
③ 사건 전후 윈도우의 비정상 수익률 : 실제 수익률 - 평소(추정 구간) 평균 수익률
④ 클러스터별 평균 누적 비정상 수익률(CAR) : 이 유형의 사건이 유가를 평균적으로 얼마나 움직이는가
⑤ 예측 시점의 뉴스 → 가장 가까운 클러스터 → 그 클러스터의 CAR을 피처로 사용
```

## 4. 결과

- 비정형 이벤트 피처를 추가한 뒤 **예측 방향성 정확도 약 10%p 개선**
- 클러스터별 영향(상관관계)은 메타데이터로 PostgreSQL에 저장해, 이후 에이전트가 "이 유형 뉴스가 과거에 유가를 어떻게 움직였나"를 근거로 답할 수 있게 함 → [02. 듀얼 스토리지](../02_FAISS_PostgreSQL_듀얼스토리지)

## 5. 배운 점

- **비정형 데이터는 "무엇을 측정할지"를 정해야 쓸 수 있다.** 텍스트 자체가 아니라 "그 텍스트가 정형 지표에 준 영향"을 측정 대상으로 정의한 것이 핵심이었습니다.
- **도메인의 검증된 방법론을 빌려온다.** Event Study는 금융에서 오래 쓰인 방법이라, 결과를 설명하기도 쉬웠습니다.
- 이 "정형 + 비정형 결합" 접근은 이후 퀀트 트레이딩 시스템의 Layer 2(뉴스 분석 에이전트)와 Layer 3(클러스터 영향력 기반 Meta-Learner)로 이어졌습니다.

```bash

```
