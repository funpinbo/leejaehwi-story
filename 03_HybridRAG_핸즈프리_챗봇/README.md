# 03. Hybrid RAG 핸즈프리 AI 에이전트 챗봇

> 현장 작업자가 손을 쓰지 않고 음성으로 사내 문서를 검색·질의하는 챗봇을 3일 동안 팀으로 만든 프로젝트입니다.
> 저는 **기밀 정보 마스킹**과 **Elasticsearch(Nori) + FAISS + RRF 하이브리드 검색**을 담당했습니다.

| 항목 | 내용 |
|---|---|
| 기간 · 형태 | SKALA AI 과정 · 3일 팀 프로젝트 (전공자 3 + 비전공자 3) |
| 담당 | 기밀 마스킹, 하이브리드 검색(BM25 + Vector + RRF), 비전공 팀원용 환경 가이드 |
| 기술 | Elasticsearch(Nori 형태소 분석기), FAISS(IndexFlatL2), RRF, Whisper STT |

---

## 🏗️ 구조

```
음성 질문 → STT(Whisper, 도메인 용어 initial_prompt)
         → 기밀 마스킹
         → ┬ BM25 (Elasticsearch + Nori)  ─┐
           └ Vector (FAISS)               ─┴→ RRF 결합 → Top-K 컨텍스트 → LLM 답변
```

## 🤝 팀 경험 — 비전공 팀원의 병목 해소

- 비전공 팀원들이 conda 환경, 패키지 충돌에서 반복적으로 막혔고, 구두 설명으로는 같은 문제가 반복됐습니다.
- **"이 화면이 나오면 → 이 명령어 → 이 결과가 나와야 함"** 형식의 스크린샷 가이드를 만들고, 가장 많이 반복된 질문 5개를 맨 앞에 배치했습니다.
- 결과: 팀원들이 스스로 환경 문제를 해결했고 "처음으로 내가 직접 개발한 것 같다"는 피드백을 받았습니다.
- 운영 방식: STT · 검색 · 생성 · UI를 독립 모듈로 나눠 병렬 개발, 매일 "되는 것"을 데모.

## 💡 회고

- **평가 지표가 없었다.** "잘 된다"는 체감으로 끝냈습니다. 다음에는 처음부터 RAGAS(Faithfulness, Context Recall) 같은 평가 파이프라인을 같이 만들겠습니다.
